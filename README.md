# Molecular Dynamics Simulations with VASP

A collection of tutorials, practical examples and notes on performing molecular dynamics (MD) simulations using the Vienna Ab initio Simulation Package (VASP).

## Overview

Molecular dynamics (MD) simulations are used to investigate the motion and interactions of atoms and molecules over time. The atomic trajectories are calculated by integrating the equations of motion using the forces acting on each particle at successive time steps.

VASP provides several approaches for performing molecular dynamics simulations, including ab initio molecular dynamics (AIMD) and machine-learning-assisted simulations using machine-learning force fields.

This repository follows the official VASP molecular dynamics tutorials and provides a practical starting point for learning how to set up, perform and analyse MD simulations.

* Investigating structural changes during melting.
